# TempExpo Modular Monorepo Scaffold 🚀

سقالة احترافية فائقة السرعة والقوة لتطوير تطبيقات **Expo / React Native** متبنية بنية المستودع الموحد (**Monorepo**) باستخدام **pnpm workspaces** و **Turborepo** لتقديم بيئة تطوير مرنة وقابلة للتوسيع لتطبيقات الإنتاج الضخمة.

---

## 🏗️ معمارية وهيكل المشروع (Monorepo Architecture)

يتبع المشروع نهج **Domain-Driven Design** مقسماً إلى وحدات معزولة ومرنة:

```text
├── apps
│   ├── mobile          # تطبيق الهاتف (Expo SDK 54+ / React Native / Expo Router)
│   └── api             # السيرفر الخلفي (Fastify API Server / Drizzle Postgres)
├── packages
│   ├── db              # مخططات وقواعد بيانات السحابة (Drizzle ORM / Postgres Migrations)
│   ├── ui              # نظام التصميم المركزي (Shopify Restyle / Shared UI Components)
│   └── shared          # الأنواع والميزات والتحققات المشتركة (Zod validation / Types)
```

---

## 🌟 الميزات والتقنيات الأساسية (Key Features)

### 1. طبقة البيانات ثنائية المستويات (Agnostic Data Layer)
* **قاعدة بيانات محلية أولاً (Offline-First)**: مدمج بها نظام **WatermelonDB** للتخزين والمزامنة الفائقة داخل الهاتف باستخدام SQLite Adapter.
* **قاعدة سحابية احترافية**: إدارة البيانات السحابية باستعمال **PostgreSQL** و **Drizzle ORM** مع توفير هجرات ترحيل البيانات التلقائية والآمنة.
* **محرك المزامنة حقيقي (Sync Engine)**: نظام مزامنة ثنائي الاتجاه يربط الموبايل مع الـ API بكفاءة عالية.

### 2. نظام تصميم متكامل مرن (Design System & Theme)
* مبني بالكامل على **Shopify Restyle** لتزويد التطبيق بنقاط قياس وثيمات مرنة (Light / Dark Themes).
* مدمج به حزمة مكونات أساسية جاهزة للإنتاج (`Button`, `Input`, `Card`, `AppHeader`).

### 3. دعم دولي متكامل واتجاهات ذكية (Localization & RTL)
* دعم الترجمة الاحترافية لعدة لغات (افتراضيًا **العربية والإنجليزية**) عبر `i18next`.
* تغيير فوري للاتجاهات السلسة (**RTL & LTR**) عند تبديل لغة المستخدم وإعادة تهيئة واجهة التطبيق آلياً دون تشوه.

### 4. حماية وتأمين الجلسات (JWT Auth & Session)
* حماية متكاملة للجلسات والتحقق عبر `JWT Access/Refresh` على خادم Fastify.
* حفظ وتشفير التوكنز محلياً في الهاتف بأمان تام عبر `expo-secure-store`.

### 5. نظام الإشعارات المدمج (Notifications)
* مهيأ ومعد لإرسال الإشعارات والتحكم بها محلياً وسحابياً عبر `expo-notifications`.

## 🛠️ دليل البدء السريع (Getting Started)

### المتطلبات الأساسية
* وجود **Node.js** إصدار v18 أو أحدث.
* تثبيت مدير الحزم **pnpm**:
  ```bash
  npm install -g pnpm
  ```

### 1. تثبيت التبعيات (Installation)
من المجلد الرئيسي للمشروع، قم بتشغيل الأمر التالي لتثبيت وربط كافة الحزم داخل الـ Workspaces تلقائياً:
```bash
pnpm install
```

### 2. تهيئة وتوليد قاعدة البيانات (Database migrations)
لتوليد ملفات الهجرة والتحديثات لقاعدة البيانات السحابية:
```bash
npx pnpm --filter @tempexpo/db run generate
```

### 3. تشغيل بيئة التطوير (Run Dev Servers)
لتشغيل بيئة التطوير الموحدة والتي تشمل مخدم تطبيق الهاتف المحمول ومخدم الـ API الخلفي في نفس الوقت بكبسة زر واحدة:
```bash
pnpm dev
```

### 4. بناء المشروع بالكامل (Production Build)
للتحقق وبناء كافة المشاريع والحزم والتحقق من سلامتها البرمجية:
```bash
pnpm build
```

## 🔒 معايير الأمان والأداء العالي
* **TypeScript Strict**: تفعيل الصرامة الكاملة للأنواع لضمان حماية الكود من الأخطاء أثناء وقت التشغيل.
* **Fastify Server**: تفضيل Fastify على Express لسرعته الفائقة في معالجة طلبات الـ API والمزامنة.
* **Hermes Engine**: مفعّل افتراضياً لرفع سرعة تشغيل واستجابة التطبيق وتقليص حجم الذاكرة المستهلكة في الهواتف.
